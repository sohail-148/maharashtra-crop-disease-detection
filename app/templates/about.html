About This Project

Image-Based Disease Detection of Maharashtra-Relevant Crops

This web application is the deployment layer of a research project that uses MobileNetV2 transfer learning to classify leaf diseases across four Maharashtra-relevant crops.

Crops Covered

  • Tomato — 10 disease classes (PlantVillage dataset)
  • Grape — Niphad/Nashik region dataset (4 classes) and Mendeley 2024 dataset (4 classes)
  • Chilli — COLD 2024 dataset (5 classes)
  • Sugarcane — Maharashtra dataset (5 classes) and Large dataset (10 classes)

Technology

  • Model: MobileNetV2 pretrained on ImageNet, frozen base with a lightweight classification head
  • Training: TensorFlow 2.18 / Keras 3.15, 70/15/15 stratified split
  • Backend: Flask 3.1
  • Database: SQLite (prediction history)
  • Explainability: Grad-CAM (Phase 12 — coming)
