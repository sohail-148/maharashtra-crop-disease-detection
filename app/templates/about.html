MSc Research Project Overview

Image-Based Disease Detection of Maharashtra-Relevant Crops

A Deep Learning Web Application with Real-World Robustness Analysis

🌿 Maharashtra Agro-Climatic Focus ⚡ Edge-Ready Lightweight CNN 🔍 Explainable AI Architecture
🛡️

Academic Research Prototype

This application is an academic research platform engineered to evaluate transfer learning, real-world domain generalization gaps, and out-of-distribution robustness across agricultural vision benchmarks. While models achieve high diagnostic accuracy on validated corpora, automated outputs should be verified in consultation with qualified agricultural extension officers before applying on-field chemical or cultural treatments.

ARCHITECTURAL HIGHLIGHTS

Core System Capabilities

🌿

4 Crop Specialists

Targeted production classifiers for Tomato, Grape, Chilli, and Sugarcane—four cash crops forming the backbone of agricultural production in Western Maharashtra, Vidarbha, and Marathwada.

🔬

33 Pathological Classes

Comprehensive diagnostic taxonomy identifying fungal blights, viral complexes (e.g. TYLCV, Chilli Murda), rusts, smuts, vascular rots, and asymptomatic healthy leaves across 31,590 verified images.

⚡

MobileNetV2 Backbone

Lightweight inverted residual bottleneck architecture ($<3.0\text{M}$ parameters) initialized with ImageNet weights. Optimized for sub-second inference latency on standard mobile and edge devices.

🧠

Grad-CAM Explainable AI

Runtime Gradient-Weighted Class Activation Mapping (Grad-CAM) computes gradient flows to highlight the specific anatomical foliar lesions driving diagnostic classification, establishing model interpretability.

Technology & Engineering Stack

Core computational libraries, frameworks, and deployment engines

🤖

Deep Learning & Transfer Learning

TensorFlow 2.18 / Keras 3.x, MobileNetV2, ImageNet pretrained weights, stratified 70/15/15 train-val-test split.

🔍

Explainable AI (XAI)

Grad-CAM visual attribution computed via runtime tf.GradientTape backpropagation with Jet colormap overlay.

🌐

Web Application Backend

Flask 3.1 WSGI framework, RESTful prediction endpoints, structured error handlers, and lazy model caching.

💾

Data Pipeline & Audit Storage

SQLite3 relational database for persistent inference history, Pillow (PIL 10.x) EXIF-aware image ingestion, and NumPy.
