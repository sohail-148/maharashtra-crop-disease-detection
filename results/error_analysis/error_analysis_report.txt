1. EXECUTIVE SUMMARY
-------------------------------------------------------------------------------------
This report provides a systematic post-training error analysis of the four
production MobileNetV2 models across all evaluation partitions:
  - 🍅 Tomato Baseline: 90.23% Acc | 9.77% Error Rate (213 errors / 2,180)
  - 🍇 Grape G1 (Niphad): 95.35% Acc | 4.65% Error Rate (19 errors / 409)
  - 🍇 Grape G2 (2024): 84.10% Acc | 15.90% Error Rate (83 errors / 522)
  - 🌶️ Chilli Baseline: 63.79% Acc | 36.21% Error Rate (105 errors / 290)
  - 🌾 Sugarcane S1 (Maharashtra): 80.47% Acc | 19.53% Error Rate (74 errors / 379)
  - 🌾 Sugarcane S2 (Large): 84.60% Acc | 15.40% Error Rate (148 errors / 961)

Key Failure Mechanisms Identified:
1. Morphological/Lesion Symmetry Confusion: Two distinct pathologies presenting similar
   color/geometry (e.g. Grape Leaf Blight vs Esca, Tomato Early Blight vs Septoria).
2. Majority Class Attractor Effect: In class-imbalanced datasets (e.g. Chilli COLD),
   the predominant class (Cercospora, 135 test samples) disproportionately absorbs
   confused predictions from smaller, ambiguous classes (Nutritional Deficiency: 75% error).
3. Subtle Symptom Attenuation: Non-necrotic viral symptoms (Sugarcane Mosaic, faint chlorosis)
   are frequently absorbed by the Healthy class in field photography.
4. Apical Architecture Convergence: Pathologies affecting structural shoot tips (Sugarcane
   Smut vs Pokkah Boeng) share identical macro-silhouettes that confuse 2D CNNs.

2. GRAPE IN-DEPTH ERROR ANALYSIS (G1 NIPHAD VS G2 2024)
-------------------------------------------------------------------------------------
A. Dataset-Specific Performance Differences:
   - G1 Niphad (Regional Maharashtra) exhibits a remarkably low error rate of 4.65% (19/409).
   - G2 Mendeley 2024 exhibits an error rate of 15.90% (83/522), a 3.4x higher error density.
   - Methodological note: This represents an observed dataset-specific error pattern driven
     by differing disease taxonomies rather than domain shift alone.

B. G2 Failure Mode — Leaf Blight <-> Esca Mutual Confusion:
   - Leaf Blight is the weakest grape class (F1: 59.34%, Recall: 53.47%, Error Rate: 46.53%).
   - Major confusion pairs:
       * True Leaf Blight -> Predicted Esca: 32 samples (highest error in Grape)
       * True Esca -> Predicted Leaf Blight: 27 samples
       * True Leaf Blight -> Predicted Black Rot: 13 samples
   - Visual Explanation: Isariopsis clavispora (Leaf Blight) produces irregular reddish-brown
     spots with chlorotic rings, which at 224x224 input resolution closely resemble the
     interveinal 'tiger-stripe' necrotic bands characteristic of Esca.

C. G1 Niphad Error Patterns:
   - Downy Mildew (F1: 95.89%) and Healthy (F1: 96.83%) separate cleanly.
   - Only minor confusions exist: Bacterial Leaf Spot -> Downy Mildew (1 sample, 98.32% conf)
     and Powdery Mildew -> Healthy (4 samples).

3. SUGARCANE IN-DEPTH ERROR ANALYSIS (S1 MAHARASHTRA VS S2 LARGE)
-------------------------------------------------------------------------------------
A. Dataset Overview:
   - S1 (Maharashtra Regional): 19.53% error rate (74/379). Weakest: Mosaic (28.99% error).
   - S2 (Large Sugarcane): 15.40% error rate (148/961). Weakest: Rust (38.30% error), Smut (42.55% error).

B. Key Confusion Clusters:
   1. S1 Red Rot Foliar Cross-Contamination:
      * 10 Red Rot samples predicted as Brown Spot (a class primarily present in S2).
      * 8 Red Rot samples predicted as Rust.
      * Red Rot midrib and foliar red lesions share visual features with Brown Spot necrotic margins.
   2. S2 Smut <-> Pokkah Boeng (Apical Shoot Distortion):
      * 14 Smut samples predicted as Pokkah Boeng.
      * Both diseases attack the growing point/terminal spindle, producing twisted stalks.
   3. S2 Brown Spot -> Yellow Leaf Disease (24 samples):
      * When brown leaf spots become confluent on senescing leaves, the background chlorosis
        triggers Yellow Leaf Disease features with high confidence (up to 95.89%).
   4. S1 Mosaic -> Healthy Leaves (9 samples) & Yellow Leaf (8 samples):
      * Subtle light/dark green mosaic patterns are attenuated under field glare.
   5. Strongest Classes:
      * Sett Rot (100% recall, 0.9949 F1) and Grassy Shoot (96.15% recall, 0.9709 F1) are near-perfect.

4. CHILLI IN-DEPTH ERROR ANALYSIS (WHY 63.79% ACCURACY?)
-------------------------------------------------------------------------------------
Chilli COLD represents the lowest performing production baseline in the project.
A rigorous audit reveals three concrete empirical factors:
1. Severe Class Imbalance & Majority Attractor:
   - Cercospora Leaf Spot comprises 46.5% of the test set (135/290 images).
   - Nutritional Deficiency (40 images) has a catastrophic 75.00% error rate (only 10/40 correct),
     with 19 samples misclassified as Cercospora.
   - Healthy (50 images) has a 40.00% error rate, with 13 misclassified as Cercospora.
   - Murda Complex (41 images) has a 53.66% error rate, with 10 misclassified as Cercospora.
2. Complex Natural Field Backgrounds:
   - Unlike PlantVillage (uniform lab backgrounds), COLD images feature hand-held leaves with
     fingers, dry soil, strong sunlight, shadows, and camera blur.
   - Soil specks and specular reflections mimic Cercospora lesions.
3. Non-Focal Symptom Ambiguity:
   - Nutritional deficiency (interveinal yellowing) and Murda complex (leaf curling/crinkling)
     are whole-leaf physiological/viral conditions lacking localized lesion margins.

5. TOMATO IN-DEPTH ERROR ANALYSIS
-------------------------------------------------------------------------------------
Overall: 90.23% Test Accuracy | 90.18% F1 across 2,180 test images.
A. Class Ranking by Difficulty:
   1. Early Blight (F1: 71.09%, Error Rate: 37.50% — 45 errors / 120)
   2. Target Spot (F1: 78.67%, Error Rate: 15.48% — 26 errors / 168)
   3. Spider Mites (F1: 85.15%, Error Rate: 14.43% — 29 errors / 201)
   4. Leaf Mold (F1: 86.36%, Error Rate: 16.67% — 19 errors / 114)
B. Major Confusion Mechanisms:
   - Early Blight distributes into Septoria (13), Late Blight (11), and Target Spot (8).
     All four diseases produce brown/black necrotic foliar lesions with concentric or punctate marks.
   - Spider Mites feeding stippling mimics Target Spot (19 samples misclassified as Target Spot).
   - Strongest: Yellow Leaf Curl Virus (F1: 97.80%, 643 images) and Healthy (F1: 94.71%).
